## 二、AI 生图素材（需 OpenRouter Key）

一键生成 3 张水科技风格素材（汇流线理念插画 / 浸润渐变背景 / 科研实训插画）：

```bash
export OPENROUTER_API_KEY=sk-or-xxx   # https://openrouter.ai/keys 获取
bash scripts/generate-assets.sh
```

产出 `public/assets/ai/*.png`。提示词已按平台视觉规范设计：
白底、冰蓝/青绿、低对比、no text。生成后请人工检查构图与文字。

**声明**：AI 生图为插画示意，不替代真实照片与实验数据图。
